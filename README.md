# Poeira Maldita: Redenção

Jogo de tiro ao alvo no faroeste, feito com HTML, CSS e JavaScript puro. Funciona direto no navegador, sem instalar nada.

## Como jogar

- Clique (ou toque) nos **bandidos de lenço vermelho** antes que eles atirem em você.
- **Não atire nos moradores** de chapéu claro e camisa azul.
- Você tem 3 vidas. Perde uma vida quando um bandido escapa ou quando acerta um morador.
- Seis balas no tambor. Aperte **R** ou o botão **Recarregar** para recarregar.
- Quanto mais pontos, mais rápido o jogo fica.

## Jogar online

Depois de ativar o GitHub Pages: `https://henrique2711.github.io/Bad-Dust-Redemption/`

## Rodar no computador

Baixe os arquivos e abra o `index.html` no navegador.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: visual
- `game.js`: lógica do jogo
